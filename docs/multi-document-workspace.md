# 中文界面与多文档窗口工作区

日期：2026-10-21。上一版可回退基线：`751b118f`（同一 PDF 双原生窗口）。

## 本次目标

- 默认使用简体中文，复用并检查已有完整中文词库；文件名、文档内容、协议和技术标识保留原文。
- 同一 PDF 可创建多个独立阅读视图，共享文档、批注、保存和撤销历史。
- 在一个软件窗口里提供可移动、缩放的文档子窗口，可混合相同及不同 PDF，并提供平铺和层叠。
- 保留独立系统窗口入口；关闭保护、输入焦点、渲染任务和草稿必须各自正确。
- 继续使用本项目内 `.tools` Rust 环境，阶段性 Git 提交，不推送远端。

## 设计

沿用唯一 Session 和每视图独立 UI/渲染器。文档编号只确定编辑对象，视图编号确定窗口；不能再以文档编号充当窗口身份。内部分窗使用 egui 原生子窗口容器，保持单进程共享文档，避免副本同步与磁盘竞争。新增视图时自动平铺，之后可拖动、缩放或重新排列。键盘操作只作用于选中的子窗口，保存提示与未发布草稿不能被关闭操作绕过。

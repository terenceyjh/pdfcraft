# 固定分栏阅读工作区

日期：2026-10-21。基线：`4926c89b`；分支：`feat/shared-document-windows`。

## 目标与路线

用户明确要求保留浏览器式标签，并将阅读区改成直接并排的固定分栏。每栏铺满可用高度，拖动栏间分隔线调整宽度；不再使用可移动、层叠的文档子窗口。同一文件可重复开栏，不同文件也可并排；翻页、缩放、笔记草稿独立，同文件共享修改、保存和撤销。

1. [x] 检查现有 Session/视图共享、焦点与关闭保护，记录基线和本路线。
2. [x] 以固定子区域替换浮动文档窗口，支持分隔线调宽和随主窗口缩放。
3. [x] 顶部提供“并排阅读”入口，直接并排现有标签；标签右键提供“在右侧分栏打开”，重复操作可多开同一文件。
4. [x] 精简每栏标题与阅读工具，保留独立导航、批注、保存和草稿保护；更新中文及已有语言词库。
5. [x] 回归不同文件、重复文件、多栏、焦点、调宽、关闭、共享保存/撤销和全屏；构建并运行真实桌面应用检查布局。
6. [x] 更新 AGENTS.md、功能记录与使用说明，提交通过检查的代码，推送到个人 fork，并核对远端提交。

## 实现约束

- 复用已有唯一 Session、每视图独立 DocView/渲染器以及 RAII 借用，不通过文件副本同步。
- 文档区域在阅读工作区内直接布局与裁剪，不使用文档浮动 Window/Area。
- 现有 `view.new_pane`、`view.tile_windows`、`view.cascade_windows` 控制编号保留兼容，依次表示右侧开栏、并排已打开标签、重置栏宽；旧的层叠行为被固定分栏替代。
- 狭窄主窗口或栏数较多时提供水平滚动，避免把每栏压成无法操作的宽度；关闭分栏后自动重新填满阅读区。
- 独立系统窗口功能继续保留。额外分栏与栏宽暂不跨重启恢复。
- 调试仅使用项目忽略目录中的合成 PDF，不改用户文件。工具链、缓存和构建输出继续留在本项目。

## 使用方法

1. 打开两份或更多 PDF，点击顶部标签栏旁的“并排阅读”。当前标签显示在左侧，其他已打开文件各占右侧一栏；原标签继续保留。
2. 同一个 PDF 需要看两个章节时，右键该文件标签选择“在右侧分栏打开”。重复选择即可多开。也可使用“视图”菜单中的同名命令，或分栏内部“菜单”中的入口。
3. 点击需要操作的栏；各栏顶部有自己的页码与缩放控件。拖动栏间竖直分隔线调宽，“视图 → 重置分栏宽度”恢复等宽。
4. 右侧栏的“注释”打开自己的批注面板。较窄的栏将面板放在下部，以便继续看到 PDF；输入笔记后按回车发布。同一 PDF 的其他视图立即共享批注与修改，各栏阅读位置和未发布草稿独立。
5. 分栏内部“菜单”提供保存、另存为、撤销、重做和查找。不同 PDF 保持独立；同 PDF 共享保存目标与撤销历史。
6. 点击右侧栏标题的 × 关闭该视图。剩余分栏会重新占满阅读区；关闭所有额外栏后返回原来的标签页阅读。草稿及最后一个已修改视图仍会阻止直接关闭。

“视图 → 在新窗口中打开”继续创建独立系统窗口。栏数较多时在阅读区底部水平滚动。主视图继续提供原有完整编辑工具，额外栏提供阅读与批注常用工具。

## 自动化与回归

使用原有显式启用并认证的 `--control` 通道：`ui.window {action:"open",doc:1,kind:"embedded"}` 添加固定栏，`view.new_pane/view.tile_windows/view.cascade_windows` 分别对应右侧开栏、并排标签、重置栏宽。协议编号保持兼容，不新增监听器。

`ui.state.document_workspace` 返回 `layout:"columns"`、主栏矩形和可见阅读区矩形；`document_windows` 中的 `rect` 是每栏的实际矩形（水平滚动后可以位于可见区之外）。输入和截图继续使用主窗口控件树，状态/设置/命令仍可按独立视图编号定位。

合成回归已实际观察到旧布局因各阅读区不在同一行而失败；另一个回归实际验证：若让后续系统窗口渲染阶段提前承认分栏的修改，主视图刷新断言会失败。修复后重新执行，结果记录于下方。
